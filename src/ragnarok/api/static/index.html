                      BEIR SciFact

                      Wadden et al., EMNLP 2020
                    		
                    Layer A: IR Ablation
                    Validates foundational Information Retrieval precision against peer-reviewed scientific claims. Used to benchmark all 4 retrieval strategies (Dense vs. BM25s vs. Hybrid RRF vs. Cross-Encoder) and prove why RRF fusion delivers superior rank saturation.
                    300 test queries (official BEIR test.tsv split) evaluated against 5,183 scientific abstracts (100% verified relevance labels).
                    0.7332 nDCG@10
Recall@10: 85.11%		
                  

                  

                    
                      BEIR NFCorpus

                      Boteva et al., ECIR 2016
                    		
                    Layer A: Biomedical IR
                    Tests cross-domain retrieval generalization into specialized clinical and nutrition literature. Verifies that RAGnarok's Hybrid RRF engine generalizes across complex medical nomenclature without domain-specific re-tuning.
                    323 test queries (full test split) evaluated against 3,633 medical abstracts across 12,335 relevance pairs (with 95% Confidence Intervals).
                    0.3563 nDCG@10
MRR@10: 0.5629 (±0.048)		
                  

                  

                    
                      ACL RGB Benchmark

                      Chen et al., ACL 2024
                    		
                    Layer B & C: Grounding
                    Measures generator noise robustness when ground-truth answers are submerged in 80% distractor noise, and tests zero-speculation negative rejection when positive evidence is withheld or contradictory.
                    100 curated benchmark cases (50 noise-submerged instances with 4 distractor docs each + 50 unanswerable negative rejection queries).
                    100.0% Robustness
98.0% Negative Rejection		
                  

                  

                    
                      Microsoft BIPIA

                      Ying et al., Microsoft 2024
                    		
                    Layer D: Security Gateways
                    Evaluates multi-surface defense-in-depth against Indirect Prompt Injection (IPI) attacks embedded as Trojan payloads in documents and code snippets to poison DuckDB or trigger context exfiltration.
                    100 benchmark documents (75 Trojan text and code attack payloads + 25 clean benign control documents).
                    100.0% ADR
0.00% DB Contamination		
                  

                  

                    
                      MultiHop-RAG

                      Tang et al., 2024
                    		
                    Layer B: Multi-Hop
                    Tests multi-document cross-chunk reasoning across 4 reasoning archetypes (Comparison, Inference, Temporal, Null), evaluating joint evidence recall across 2-4 supporting articles and Context Window Expansion gain.
                    200 balanced test cases (50 comparison, 50 inference, 50 temporal, 50 null queries) evaluated against 609 multi-source news articles (TechCrunch, Verge, Mashable).
                    58.0% Joint Recall@10
100.0% Null Rejection		
                  

                  

                    
                      RAGAS Golden Reference

                      Es et al., EACL 2024
                    		
                    Layer A & B: RAG Triad
                    Enforces deterministic, regression-free verification of the classic RAG Triad (Faithfulness, Context Precision, Context Recall, Answer Relevancy) against curated enterprise domain documentation.
                    20 curated golden cases covering enterprise architectural specifications and technical constraints.
                    0.970 Faithfulness
0.963 Context Precision
